# 🚀 Multi-Platform Post Composer

A modern web application that helps users create, customize, and preview social media posts for multiple platforms from a single interface. Designed with a clean UI and responsive experience, it streamlines content creation for creators, marketers, and businesses.

---

## ✨ Features

* 📝 Compose posts for multiple social media platforms
* 👀 Real-time post preview
* 🎨 Clean and responsive user interface
* ⚡ Fast performance with Vite
* 📱 Mobile-friendly design
* 🔄 Easy customization and extension
* 🌙 Modern UI/UX

---

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/jazz1329/jaskiratsingh_EXP1_24BDA70001.git
```

### 2. Navigate to the project

```bash
cd multi-platform-post-composer
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Build for production

```bash
npm run build
```

### 6. Preview the production build

```bash
npm run preview
```

# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some Oxlint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
